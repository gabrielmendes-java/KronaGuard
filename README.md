# KronaGuard 🛡️

**KronaGuard** é um sistema ágil de rastreabilidade e controle de garantias para assistências técnicas. Focado em velocidade na bancada, permite gerar comprovantes digitais com validação de CPF, cálculo automático de validade e histórico completo de atendimentos.

---

## 🚀 Tecnologias Utilizadas
* **Java** (Versão atual do projeto)
* **Spring Boot** (Web, Data JPA, Validation)
* **Thymeleaf** (Renderização de Views no Servidor)
* **Tailwind CSS** (Estilização moderna e responsiva)
* **Banco de Dados Relacional** (H2 / MySQL / PostgreSQL)

---

## ✨ Principais Funcionalidades
* Emissão rápida de termos de garantia para balcão.
* Validação automática de CPF com suporte a máscara.
* Cálculo dinâmico de validade com base nos dias de garantia informados.
* Consulta e histórico de atendimentos por termo ou cliente.
* Registro de ocorrências e controle de mau uso.
